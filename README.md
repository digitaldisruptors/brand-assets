# brand-assets

Public brand assets of Digital Disruptors L.L.C that have to be reachable from the open Internet, for example images in e-mails: a mail client cannot
load an image from our private hosts.

| File | Used by |
|---|---|
| `email/dd-logo-horizontal-blue-480.png` | the invitation and notification e-mails of our password manager. 480 x 108 px, transparent background: the horizontal blue logo of the brand kit, scaled |

The logo is a trademark of Digital Disruptors L.L.C. Do not change its proportions or colours. Reference an image by a commit URL
(`https://raw.githubusercontent.com/digitaldisruptors/brand-assets/<commit>/email/<file>`) so that a later change cannot alter what an old e-mail shows.

Nothing else belongs here: no credentials, no internal addresses, no customer data, no source files of the brand kit.
